# 🛡️ Zcash Agent SDK

A lightweight Python SDK designed for autonomous AI agents to interact with Zcash nodes, validate Unified Addresses (UAs), and monitor shielded network state.

## Features
- ⚡ **Lightweight & Fast:** Zero heavy dependencies.
- 🛡️ **Shielded Ready:** Native support for Zcash RPC endpoints & UA structure.
- 🤖 **Agent Ready:** Seamless integration for Python agent frameworks.
